    📱 Paiements Samsung Pay notés tout seuls

    Quand tu paies avec ton téléphone, la notification (Samsung Wallet ou ta banque) est envoyée à Jarvis qui l'inscrit au bon jour. Tu n'as plus à dire que tes paiements en espèces.

    1. Installe Automate (LlamaLab, gratuit) sur ton S23+ depuis le Play Store.
    2. Crée un flux : Flow beginning → Notification posted? (Package : com.samsung.android.spay — et/ou l'appli de ta banque ; « Proceed : when changed » ; sorties Title → titre, Message → texte, Package → appli).
    3. Ajoute HTTP request : Méthode POST, adresse ci-dessous, Content type application/json, corps :
      {"titre":titre,"texte":texte,"appli":appli} (bouton « fx » pour écrire une expression), en-tête X-Jarvis-Cle = la clé.
    4. Relie la sortie de HTTP request au bloc Notification posted? (boucle), puis Start. Autorise l'accès aux notifications quand Android le demande.
    5. Paie un petit montant : il apparaît ici en quelques secondes (📱 dans l'historique).

    La clé ne sert qu'à ça : sans elle, personne ne peut écrire dans ton budget. Guide complet : C:\Jarvis\docs\GUIDE-SAMSUNG-PAY-AUTOMATE.md.
